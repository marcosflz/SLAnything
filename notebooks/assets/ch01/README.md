# Recursos visuales del capítulo 1

## Figuras del libro

`fig_1_1_jerarquia_ia.png` … `fig_1_9_roadmap.png` son las figuras 1.1–1.9 extraídas del
PDF de *Build a Large Language Model (From Scratch)* de Sebastian Raschka (Manning, 2024).
Se incluyen **solo como apoyo educativo personal**; todos los derechos pertenecen a Manning
Publications y al autor. No redistribuir.

## Diagramas propios

- `fig_es_etapas.png`: las dos etapas de un LLM (pretraining y finetuning), en español.
- `fig_es_roadmap.png`: las tres etapas del libro y los capítulos que las cubren.

Se generan con `tools/make_ch01_assets.py` usando matplotlib.
