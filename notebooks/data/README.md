# Datos

## `quijote_fragmento.txt`

Fragmento de *El ingenioso hidalgo don Quijote de la Mancha*, de Miguel de Cervantes
Saavedra, usado como corpus didáctico para el modelo de n-gramas del capítulo 1.

- **Fuente:** Project Gutenberg, eBook #2000 — <https://www.gutenberg.org/ebooks/2000>
- **Licencia:** dominio público en Estados Unidos; se aplican los términos de Project
  Gutenberg.
- **Preparación:** se toma el texto desde «En un lugar de la Mancha» hasta aproximadamente
  400 000 caracteres, se normalizan espacios y se corta en el último punto. No se usa para
  entrenar un modelo real, solo para contar secuencias y generar texto de juguete.

El archivo completo de Gutenberg no se incluye para mantener el repositorio ligero; puede
descargarse desde el enlace anterior.
